# Rider — инфра

Бизнес-схема в `BUSINESS.md`, домены и Kratos в `PLAN.md`. Здесь закрытый стенд, на котором эти домены открываются до публичного DNS.

Локально, пока тачки нет, Postgres, Redis, ClickHouse и Kafka описаны в `infra/compose.yaml` (проект `rider-infra`). Kratos по-прежнему на своём Postgres из `kratos/compose.yaml` и к новой базе `kratos` не подключён.

| Сервис | Откуда |
| --- | --- |
| Postgres `app`, `kratos`, `svix` | `localhost:5432`, пользователь `rider` |
| Redis | `localhost:6379` |
| ClickHouse, база `rider` | HTTP `localhost:8124`, native `localhost:9001` |
| Kafka | `localhost:9092`, из контейнеров `kafka:29092` |
| Kafka UI | `https://kafka.rider.io`, запасной вход `http://localhost:8088` |

## Тачка

Нужна пустая машина с SSH. На `leadmarket-docker1` порт 443 уже занимает хостовый nginx текущего Lead Market, этот порт не забираем.

На новой тачке 443 должен быть свободен. Проверка:

```bash
sudo ss -lptn 'sport = :443'
```

Пустой вывод значит, что порт можно отдать Traefik.

CI/CD для этого стенда не делаем. Стек поднимается на тачке вручную, по SSH.

## Traefik

Traefik на тачке слушает 80 и 443 и является единственным входом. Контейнеры Kratos, UI и будущего API наружу порты не публикуют. Traefik выбирает контейнер по заголовку `Host`.

Сертификаты те же, что уже выписаны локально через mkcert, по одному на апекс:

- `*.rider.io` и `rider.io`
- `*.chase.io` и `chase.io`
- `*.marshall.io` и `marshall.io`

Traefik читает их из файла рядом с динамическим конфигом, как сейчас `dynamic/rider-tls.yml` на локальном стенде. Один сертификат покрывает один уровень: `id.chase.io`, `buyer.chase.io`, `partner.chase.io`, `api.chase.io`. Имя `a.b.chase.io` он не покрывает.

## Закрытый контур

Публичный DNS не меняем. Снаружи `chase.io` и `marshall.io` остаются теми доменами, которыми они являются в интернете.

Доступ только с машин, где сделаны две вещи.

1. В `/etc/hosts` каждое имя смотрит на IP тачки. Масок в hosts нет, поэтому пишется каждое имя отдельно: `id`, `buyer`, `partner`, `api` и `owner` для `rider.io`, `chase.io`, `marshall.io`.
2. В систему и браузер установлен корневой сертификат mkcert, которым подписаны эти файлы. После этого браузер открывает `https://id.chase.io` без предупреждения.

Локальный dnsmasq сейчас отдаёт эти имена на `127.0.0.1`. Для тачки те же имена в hosts должны указывать на её IP, иначе браузер останется на локальном стенде.

Порт 443 с ноутбука до тачки должен быть доступен. У кого нет строки в hosts и корневого сертификата, тот на этот контур не попадает.
