## 2. Статусы лидов — sold / delivered / approved

**Проблема:** один бейдж **Status** смешивает этапы. **Sold** и **Delivered** визуально похожи и путаются; для CPA ещё нужны **approved / rejected** (и pending).

**Домен (напоминание):**

| Этап | CPL (типично) | CPA |
| --- | --- | --- |
| Продажа (charge партнёра) | sold | sold |
| Доставка в/postback | delivered | — / отдельная семантика |
| Конверсия | — | approved / rejected / pending |

**Варианты UI:**

1. **Три колонки в таблице:** Sold · Delivered · Conversion (или Approval) — булевы/мини-бейджи «Yes / No / —».
2. **Одна колонка в таблице** (например только **Sold** или укороченный primary status), **детализация в карточке** `LeadDetailDialog` — блок «Lifecycle» с тремя строками.
3. **Гибрид:** в таблице **Sold** + **Conversion** (для CPA), delivered только в карточке для CPL.

**Решения на завтра:**

- Согласовать термины в UI с бэкенд-полями (что уже отдаёт API для partner leads).
- Не дублировать одно и то же словом в разных колонках (разные цвета/иконки для sold vs delivered).
- CPL: delivered часто следует за sold — нужен ли отдельный «не delivered» в списке или достаточно pending-состояния.

**Файлы:** `Leads.vue`, `LeadDetailDialog.vue`, маппинг статусов (composable / `leadStatus`).

## 3. Поиск по ID на трёх страницах + рост фильтров

**Задача:** единообразный **поиск по ID** (order id `OR-…` / uuid lead / offer `OF-…` — уточнить per page).

**Сейчас:**

- **My leads** — есть поле **Order ID** (`filterOrderId` в `Leads.vue`).
- **My orders** — нет быстрого поиска по Order ID (есть advanced filters).
- Третья страница — уточнить: **Reports**? **Buy leads** (Offer ID)? Зафиксировать в начале сессии.

**Паттерн фильтров при росте числа полей:**

- Уже есть **More filters** на Leads / Orders — продолжить модель: 1–2 поля всегда видны (ID, период), остальное в раскрываемой панели.
- Альтернативы: второй ряд фильтров; drawer «Filters» на узкой ширине; chips активных фильтров под строкой.
- Вынести общий компонент **IdSearchField** (placeholder, нормализация `OR-` / uuid).

**Продумать:**

- Debounce и сброс пагинации при поиске.
